# Privacy Policy

This policy explains what data **\[Us ? \]** ("the Bot") collects and how it is used.

**1. Data we collect**

- **Discord identifiers:** user IDs, usernames, server (guild) IDs and names, channel IDs, role IDs, and message IDs.
- **Command data:** the content of messages that start with the Bot's prefix (or slash commands) so the Bot can run them. The Bot only reads message content to process commands and enabled features.
- **Server configuration:** settings, permissions lists, moderation and logging setups, welcome/invite settings, and similar data saved by server admins.
- **Moderation data:** actions such as jails/mass jails (including the roles stored so they can be restored), blacklists, and logs.
- **Voice activity statistics:** time spent in voice channels, hourly activity, and which members shared voice channels (used by features such as heatmap and duo).
- **Economy/game data:** in-bot balances, bounties, clans and similar feature data.
- **Presence data:** status, device and activity information is read live from Discord when a staff member runs a command that requires it. It is not stored permanently.
- **\[Add here anything else, e.g. DM logs, message logs, if those features store content.\]**

We do **not** collect passwords, payment details, or your real name. Payments are handled entirely by Discord.

**2. How we use data**

To run commands and features, enforce moderation settings, show statistics, provide premium features, prevent abuse, and fix bugs.

**3. Data sharing**

We do not sell your data. Data is not shared with third parties, except where required by law or to protect the safety of users, or with the hosting provider that stores the Bot's database.

**4. Data storage and retention**

Data is stored on our server/hosting **\[usa Los Angeles\]**. We keep it as long as the Bot is in the relevant server or as needed to run the features. When the Bot is removed from a server, that server's data may be deleted **\[within X days\]**.

**5. Your rights and data deletion**

You can request access to, or deletion of, the data linked to your Discord ID by contacting **\[zakariahmaiti@gmail.com\]** or our support server. Server owners can request deletion of all their server's data. We will respond within a reasonable time (usually 30 days).

**6. Children**

The Bot is not intended for anyone under 13 (or the minimum age required by Discord in their country). We do not knowingly collect data from them, and will delete it if we learn of it.

**7. Security**

We use reasonable measures to protect data, but no system is 100% secure.

**8. Changes**

We may update this policy; the "Last updated" date will change. Continued use means you accept the update.
